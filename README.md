## Usage
This is well tested, I use it daily. If this fails to install, install it with BRAT directly from GitHub.

Moves the active and selected files to the folders of their backlinking files, if exactly one backlink exists. Moves can be undone one with the plugin 'File Undo'.(https://community.obsidian.md/plugins/file-undo ). 

Adds the command 'Move to the folders of linking (“parent”) files'.

Also helpful to organize into folders is my plugin "Move to subfolder": ttps://community.obsidian.md/plugins/move-to-subfolder
